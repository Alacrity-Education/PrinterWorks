v2.3 MARKER-SPLIT STUDY -- decision report
=========================================================================================================================
200880 decoder runs total.  Calibrated sampler = recon/synth.py's fitted model; lock stage =
embedded_v2._seed + ._refine x2 (as decode_state runs it), then its marker-forced
calibration + decision passes.  All three candidate splits are 6 marker bytes, so every
frame is 3 + 22 + 3 = 28 B = 224 bits: the frame LENGTH the seed lock solves is identical
and any difference comes only from where the marker EDGES sit.

  lock%      _seed returned K inside [K_MIN, K_MAX] (else R1)
  eps err    |K_NOM/K - 1 - eps_true|, percentage points
  t0 err     |(tau - BIAS_U)*TU_ns - t0_true|, ns
  R2ok%      zero marker-bit violations
  R1-4ok%    the R1..R4 refusal gates all pass
  bitexact%  payload' decoded bit-for-bit correct (delivery proxy)

=========================================================================================================================
VERDICT
=========================================================================================================================
  lock success is 100.00 / 100.00 / 100.00 % -- the primary metric does not discriminate at all.
  eps/t0 error medians are equal across splits; only the p90 tail moves, and section 6
  shows that tail tracks the presence of an 8-zero marker byte, NOT the split:
    4+2 sizing WITHOUT a 00 byte vs (a): 283 / 309, chi2 = 1.06  -> no measurable difference
    2+4 sizing WITHOUT a 00 byte vs (a): 310 / 402, chi2 = 11.63  -> (a) is BETTER
  And with the content matched, 3+3 stays the best sizing: the best 3+3-with-00 variant
  reaches 71.05 % bit-exact on the plateau vs 68.27 % for the best 4+2-with-00 variant.

  -> KEEP SPLIT (a) 3+3, HEADER = FF AA 65, TRAILER = 9A 55 FF.
     No split measurably wins once marker content is controlled.

  SEPARATE FINDING FOR THE OWNER (not acted on here): dropping the 0x00 probe DOES cost.
     Every variant carrying an 8-zero marker byte beats every variant without one, on
     plateau bit-exactness and on the lock-error tail, regardless of split.  PROTOCOL.md's
     rationale that payload zero runs 'serve the same purpose' is not borne out here.
